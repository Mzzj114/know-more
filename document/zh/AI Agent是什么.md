# AI Agent 是什么

## 背景与定义

AI Agent（智能体）是建立在语言模型之上的一类智能应用系统。如果说大语言模型是一个"大脑"，那么 AI Agent 就是为这个大脑配备了"手和眼睛"——它不仅会思考，还能行动。

## Agent 是语言模型的拓展

Agent 与大语言模型最核心的区别在于**工具调用**（Function Calling / Tool Use）。Agent 可以联网搜索、执行命令、操作文件、调用 API 等，把语言模型的推理能力延伸到现实世界。

除此之外，Agent 通常还具备以下扩展能力：

- **技能（Skills）**：预定义的指南或工作流，告诉 AI 如何完成特定任务
- **更复杂的记忆系统**：不仅能记住对话历史，还可能包含长期记忆、知识库检索等
- **规划与执行循环**：自动拆解任务，逐步执行并检查结果

不同 Agent 的实现方式各不相同，目前没有统一的技术标准。有些 Agent 设计简单，只增加了工具调用；有些则高度复杂，整合了多种子系统。

## AI Agent 应用的例子

你将越来越多地在日常工具中接触到 Agent。以下是一些典型例子：

- **DeepSeek 网页版**：DeepSeek 推出的对话产品，在基础语言模型之上集成了联网搜索（Web Search）等功能，能主动获取最新信息，是「模型 + 工具」的典型 Agent 架构。
- **OpenAI Codex**：OpenAI 推出的 AI 编程 Agent，能在终端中执行命令、读写文件、运行代码，将语言模型的推理能力直接延伸至开发环境。
- **OpenClaw（龙虾）**：2024 年由奥地利开发者发起的开源 AI Agent 框架（MIT 协议），图标为红龙虾，国内圈内俗称「养虾」。2026 年爆发式流行。它能接管终端和浏览器、对接微信/飞书等 IM，7×24 小时后台运行。架构上分为模型层（大脑）、智能体层（规划）和技能层（5700+ 插件），一句话总结：ChatGPT 是「动口」，龙虾是「动手」。

> 你可能注意到了，Agent和语言模型不一定是绑定的。比如 Anthropics 的 Agent 软件 Claude Desktop 指支持 Anthropics 自家的模型，然而 OpenClaw 支持数十种提供商的模型，你甚至还能使用本地模型或你自己的模型。
