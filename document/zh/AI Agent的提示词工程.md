# AI Agent 的提示词工程

## 基础原则

面向大语言模型的提示词工程技巧，在 AI Agent 中仍然全部适用。但由于 Agent 具备更强的能力（工具调用、记忆系统、技能等），我们有一些额外的提示词技巧值得关注。

## 工具使用

Agent 是否使用工具、使用哪些工具，最终都由语言模型决定。因此：

- 如果你希望 Agent 使用特定工具，可以直接在提示词中指明
- 如果你不希望 Agent 动用工具（例如只需要纯文本回答），同样可以明确说明
- 你可以询问 Agent 有哪些可用工具——这些信息在其上下文中

当然，如果任务场景足够明显，你也可以完全不提工具的事，交给 Agent 自行判断。

## 记忆与上下文

进入 Agent 上下文的信息远不止你与它的当前对话记录。具体包含什么取决于 Agent 的软件设计——可能有长期记忆、知识库、用户档案等。你无需重复说明它已有的上下文。

了解你的 Agent 拥有哪些上下文信息，可以帮助你写出更精简有效的提示词。

## 技能（Skills）

Agent Skill 是较新的概念：一份预先写好的指南，告诉 AI 如何完成某类任务。所有可用的 skill 存在于 Agent 的上下文中。

与工具一样，你可以明确指定 Agent 使用某个 skill，也可以不说额外的话，让 Agent 自行判断。

> 如果你的 Agent 不支持 skill 功能，你也可以直接指示它读取某份 skill 文件来使用那份指南。

## 安全问题

能力强大的 AI Agent 在方便高效的同时也是安全隐患。从提示词的角度保障安全，应当注意：

- 避免下达模糊不清的指令，以免 Agent 做出预期之外的操作
- 不要让不受信任的人有机会与你的 Agent 交流——你不知道他们会做什么
